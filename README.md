# Proyecto web de clase

Aplicaciones HTML, CSS, JavaScript y Vue.js.

## Ejecutar el servidor

```bash
npm start
```

Abrir:

- `http://localhost:3000/registrovue.html`
- `http://localhost:3000/reinscripcion.html`

La API guarda los registros en `alumnos.json` mediante `GET /api/alumnos` y `POST /api/alumnos`.
